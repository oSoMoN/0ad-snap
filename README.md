# 0 A.D. snap package

[![0ad](https://snapcraft.io/0ad/badge.svg)](https://snapcraft.io/0ad)

This is the snap packaging for [0 A.D.](https://gitea.wildfiregames.com/),
a free, open-source, historical Real Time Strategy (RTS) game currently under
development by Wildfire Games, a global group of volunteer game developers.

## Supported architectures

* amd64 (aka x86_64)
* arm64 (aka aarch64)

## Branches / channels

* **stable** tracks the latest stable release
* **candidate** publishes release candidate builds prior to a stable release
* **edge** publishes [nightly builds](https://jenkins.wildfiregames.com/job/0ad-bundles/) of a recent development snapshot

## Reporting issues

Use this project to report issues that are specific to the snap package.

For general game issues (or if in doubt),
please report them [against the upstream project](https://gitea.wildfiregames.com/0ad/0ad/issues/new),
and make it explicit that you are using the snap package.
